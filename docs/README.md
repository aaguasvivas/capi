# Capi docs

Read in this order. Each file assumes the ones above it.

1. `../CLAUDE.md`: monorepo layout, commands, and the rules every change follows (shared strings only in packages/i18n, no em dashes, two clients for realtime changes).
2. `PLAYBOOK.md`: what Capi is, the pinned mobile stack, verification gates, feature and privacy truth, store identity, asset generator scripts.
3. `RELEASE.md`: the store submission runbook (EAS build and submit, App Store Connect, Google Play) and the post-launch idea list.
4. `m5-submission-checklist.md`: the 1.1 gate list (iMessage extension, ads, and IAP in one review). Section D3 is the single source of truth for the App Privacy answers.
5. `superpowers/specs/`: the design spec for each milestone, then `superpowers/plans/`: the implementation plan that executed it. The newest date is the current milestone.
6. `archive/`: the original web-only MVP plan and milestone log. Historical, not maintained.

Reference, open when needed:

- `store-listing.md`: paste-ready store copy (EN + ES), App Review notes, What's New.
- `m5-asc-iap-setup.md`: the App Store Connect IAP product table for 1.1.
